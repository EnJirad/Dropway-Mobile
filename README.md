# Dropway Mobile 📱

> แอพพลิเคชันมือถือสำหรับคนขับและเจ้าหน้าที่จัดส่งพัสดุ เชื่อมต่อฐานข้อมูล Neon PostgreSQL แบบ Real-time  
> พอร์ตและปรับปรุงตรรกะมาจากระบบเว็บ [Dropway](https://github.com/EnJirad/Dropway)

---

## ✨ ฟีเจอร์หลัก (Features)

### 1. 🏠 คลังบ้าน (Houses Directory)
- **โหลดข้อมูลบ้านทั้งหมดจาก Neon**: รองรับข้อมูลบ้านขนาดใหญ่ (สูงสุด 50,000+ หลัง) จากฐานข้อมูล Neon PostgreSQL
- **แสดงผลแบบ Virtualized List (`LazyColumn`)**: ประมวลผลและ render เฉพาะรายการที่ปรากฏบนหน้าจอเท่านั้น รายการนอกจอถูก recycle ทันทีเพื่อประหยัดแบตเตอรี่และหน่วยความจำ เลื่อนหน้าจอได้ลื่นไหล 60/120 fps
- **ระบบค้นหาความแม่นยำสูง (Smart Search)**: ค้นหาได้ทั้งบ้านเลขที่ (เช่น `5`, `1442/3`), ชื่อผู้รับ, เบอร์โทรศัพท์, ที่อยู่, ตำบล/อำเภอ และจุดสังเกต
- **ชิปกรองตำบล/อำเภอ**: เลือกกรองตามพื้นที่จัดส่งได้อย่างรวดเร็ว
- **One-Tap Actions**: แตะเพื่อโทรออกหาผู้รับ หรือเปิด Google Maps นำทางไปยังบ้านได้ทันที

### 2. 📷 ระบบสแกนใบปะหน้าพัสดุเต็มรูปแบบ (Complete Parcel Scanner)
ถอดแบบตรรกะและประสบการณ์ผู้ใช้จาก Dropway Web ครบ 100%:
- **Live Camera Viewfinder (Android Camera2)**: แสดงภาพสดผ่านกล้องพร้อมกรอบตรวจจับเป้าหมาย 70% กลางภาพ
- **Real-Time Label Detection & Auto-Capture**:
  - ประมวลผลทุก 250ms ด้วย `LabelDetector` วัดความสว่าง, คอนทราสต์, สัดส่วนกระดาษขาว (`whiteRatio`), และความหนาแน่นขอบตัวหนังสือ (`edgeRatio`)
  - ตรวจจับระยะใกล้เกินไป (`looksTooClose`) และแจ้งเตือนให้ถอยกล้องออก
  - ตรวจจับความนิ่งของภาพ (`frameDifference <= 9`)
  - เมื่อตรวจพบใบปะหน้าและนิ่งครบ 500ms พร้อมคงสภาพครบ 900ms ระบบจะเล่นเสียงบี๊บ `beepCapture()` และถ่ายภาพให้อัตโนมัติ!
- **Manual Shutter & Torch Control**:
  - ปุ่ม Shutter กึ่งกลางล่างสำหรับกดถ่ายทันทีโดยไม่ต้องรอระบบอัตโนมัติ
  - ปุ่มเปิด/ปิดไฟฉาย (Flashlight Torch) บนหน้าจอกล้อง
- **Image Enhancement (3x3 Unsharp Mask)**: ปรับความคมชัดของขอบตัวอักษรภาษาไทยก่อนส่งให้ OCR/AI
- **AI OCR Vision (Gemini 1.5 Flash)**: วิเคราะห์ภาพใบปะหน้า สกัดข้อมูลฝั่งผู้รับ 6 ช่อง: ชื่อผู้รับ, เบอร์โทร, บ้านเลขที่, ที่อยู่, รหัสไปรษณีย์ และเลขพัสดุ
- **Validation & Normalization (`LabelValidator`)**:
  - แปลงเบอร์โทรไทย รองรับรูปแบบ `+66`, `66`, `660`, `0066` ➔ `0...` (9-10 หลัก)
  - สกัดรหัสไปรษณีย์ 5 หลัก และเลขที่บ้าน
  - สกัดและจัดอันดับเลขพัสดุตามขนส่ง (Flash, SPX, Kerry, J&T, ไปรษณีย์ไทย)
- **Duplicate Parcel Detection**: ตรวจสอบตาราง `parcels` ใน Neon ป้องกันการสแกนซ้ำ พร้อมแจ้งเตือนหากเลขพัสดุนี้ถูกบันทึกแล้ววันนี้
- **Dropway Result Sheet**:
  - `+ เพิ่มเข้านำทาง`: เพิ่มเข้าคิวจัดส่งวันนี้ทันที (พร้อมระบบป้องกันเลขพัสดุซ้ำ)
  - `บันทึกบ้านใหม่ / อัปเดตบ้าน`: บันทึกลงตาราง houses ใน Neon
  - `แก้ไขข้อมูล`: ตรวจสอบและแก้ไขข้อมูลทั้ง 6 ช่องก่อนบันทึก
  - `บ้านใกล้เคียงที่ระบบแนะนำ`: แสดงการ์ดตัวเลือกบ้านใกล้เคียง แตะ 1 ครั้งเพื่อสลับเป็นผลหลัก
  - `ค้นหาบ้านในคลังเอง`: มีช่องค้นหาในตัวเพื่อเลือกบ้านด้วยตนเอง
  - `สแกนชิ้นถัดไป`: รีเซ็ตผลและเปิดกล้องพร้อม Cooldown ป้องกันการสแกนซ้ำใบเดิม
- **Audio & Haptic Feedback**: เล่นเสียงบี๊บแจ้งเตือนเมื่อจับภาพ, เสียงยืนยันเมื่อจับคู่สำเร็จ, และการสั่นเพื่อตอบสนองคนขับ

### 3. 🧭 นำทางและคิวจัดส่ง (Navigation & Deliveries)
- แสดงลำดับจุดส่งพัสดุประจำวัน (รอดำเนินการ / จัดส่งแล้ว / แจ้งปัญหา)
- อัปเดตสถานะการจัดส่งแบบ Real-time เข้าฐานข้อมูล Neon
- รองรับโหมดมือเดียวสำหรับคนขับ (เลือกตำแหน่งแถบปุ่ม: โหมดมือซ้าย หรือ โหมดมือขวา)

### 4. ⚙️ ตั้งค่าและการเชื่อมต่อ (Settings)
- เชื่อมต่อ Neon PostgreSQL ผ่าน HTTPS API ปลอดภัย ไม่ต้องเปิดพอร์ตฐานข้อมูลโดยตรง
- ตั้งค่า Gemini API Key สำหรับเปิดใช้งานฟีเจอร์ AI อ่านใบปะหน้าจากรูปภาพ
- ปุ่มสร้าง/ซิงค์โครงสร้างตาราง (Init Schema) และปุ่มใส่ข้อมูลตัวอย่างแม่สอด 27 จุด (Seed Data)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Language**: Kotlin 1.9+
- **UI Framework**: Android Jetpack Compose (Material 3)
- **Camera API**: Android Camera2 & TextureView
- **Backend Database**: Neon Serverless PostgreSQL (SQL over HTTPS)
- **AI Vision**: Google Gemini 1.5 Flash Vision API
- **Concurrency**: Kotlin Coroutines & Asynchronous Background Filtering
- **Build System**: Gradle 8.14 (Android Gradle Plugin 8.9)
- **CI/CD**: GitHub Actions Automated Build & Test
